# curva-ai-knowledge

Plugin de Claude Code con el **AI Knowledge de CURVA**: cómo se enseña IA y estrategia de IA a empresas, compactado.

Incluye: benchmark de 55 organizaciones (consultoras, escuelas, México/LatAm, big tech, frameworks, academias internas), patrones, huecos del mercado, modelo CURVA de programa, fórmulas y patrones de prompt, marcos (3A, madurez, roles, 13 elementos de Deloitte) y 17 lecturas con su nivel de confianza.

## Instalar (en la terminal de Claude Code)
```
/plugin marketplace add EmiLomba/curva-ai-knowledge
/plugin install curva-ai-knowledge@curva-ai-knowledge
```
Luego reinicia Claude Code y pregunta, por ejemplo: «¿cómo enseñan IA las escuelas de negocio?» o «dame una fórmula de prompt para un reporte».

## Notas
- Datos de octubre de 2026; el benchmark no se re-verificó contra las páginas fuente.
- Las lecturas son de 2023 a febrero de 2025.
- El marco 4D de Anthropic es CC BY-NC-SA: revisar antes de usarlo en un programa de pago.
